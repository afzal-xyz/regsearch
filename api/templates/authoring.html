How to write one

Read the citation and heading. Ask the question the way someone who has never read the regulation would ask it. Open "Reveal text" only when the heading is not enough — and expect the overlap meter to go amber when you do, because the words will be fresh in your mind. There is no "test this question" button, and that is deliberate: a question tuned until the current engine answers it measures the engine, not the regulation.
